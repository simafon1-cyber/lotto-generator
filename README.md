# Lotto Generator — генератор чисел Lotto Max и Lotto 6/49 для Mac

Программа для личного пользования.

* **Mac:** [скачать для Apple M1/M2/M3/M4](https://github.com/simafon1-cyber/lotto-generator/releases/download/lottery-latest/LottoGenerator-mac-apple-silicon.zip) ·
  [скачать для Intel](https://github.com/simafon1-cyber/lotto-generator/releases/download/lottery-latest/LottoGenerator-mac-intel.zip)
* **iPhone:** https://simafon1-cyber.github.io/lotto-generator/ — в Safari
  «Поделиться» → «На экран Домой»; или приложение через Xcode:
  [ios/УСТАНОВКА_IPHONE.md](ios/УСТАНОВКА_IPHONE.md)

## Что умеет

* Знает **всю историю тиражей** с официального сайта лотереи BCLC:
  Lotto 6/49 с 12.06.1982, Lotto Max с 25.09.2009.
* **Обновляется сама**: при запуске и каждые 3 часа, пока открыта. Если
  вышел новый тираж — показывает его числа. Если интернета нет, повторяет
  через 10 минут. Внизу окна видно время последнего обновления и день
  следующего тиража (6/49 — среда и суббота, Max — вторник и пятница).
* Учитывает розыгрыши **MaxMillions** (по 1 000 000 $): переключатель
  «Розыгрыши» — только основные, основные + MaxMillions, только MaxMillions.
  Суммы джекпотов в официальном файле не публикуются, поэтому их анализа нет.
* Большая кнопка **«Сгенерировать 10 вариантов»** и кнопка **«Открыть
  сайт для покупки»**: открывает официальный сайт лотереи вашей
  провинции (выбор запоминается), а варианты заранее копирует. Билет
  покупаете вы сами: входите на сайт, вписываете числа, подтверждаете.
* **Галочки и «Мои билеты».** Щелчок по варианту ставит ☑; кнопка
  «Сохранить купленные» заносит отмеченные в таблицу на вкладке «Мои
  билеты» с датой тиража. Эти комбинации генератор больше не предлагает.
  После тиража программа сама пишет, сколько чисел совпало и есть ли приз.
  Билеты, купленные раньше, добавляются кнопкой «Добавить билет вручную…».
  Список хранится в `~/Library/Application Support/LottoGenerator/my_tickets.json`.
* **Проверка на истории** (вкладка): для каждого из последних тиражей
  частоты считаются только по прошлым тиражам, каждым способом делается
  10 билетов, и считается, сколько совпало. Видно, отличается ли какой-то
  способ от случайного больше обычного разброса.
* **«Избегать комбинаций, которые часто выбирают люди»** (галочка, по
  умолчанию включена): без дней месяца 1–31 почти целиком, рядов подряд,
  «лесенок», одинаковых последних цифр. Шанс тот же, но джекпот реже делить.
* **Деньги:** у каждого билета цена (Lotto Max 1,50 $ за линию, 6/49 3 $),
  кнопка «Записать выигрыш…», итог за неделю, месяц и всего, и **лимит в
  неделю** — при превышении программа предупреждает и перед открытием сайта.
* **Уведомление** в углу экрана Mac после тиража с итогом по вашим билетам
  (пока программа открыта).
* Показывает, **сколько раз выпадало каждое число**: красные шары — чаще,
  синие — реже. Есть таблица и список последних тиражей.
* Можно выбрать период: всё время, 10 / 5 лет, год, последние 100 или
  50 тиражей. Lotto Max: до 14.05.2019 числа 1–49, затем 1–50, а с
  **14.04.2026 — 1–52** (4 линии за 6 $, розыгрыши MaxPlus). Для этого есть
  варианты периода «с 14.05.2019» и «с 14.04.2026».
* **Главный экран** показывает последний тираж каждой игры с бонусом и
  итог по вашим билетам на него: лучший результат, денежные призы,
  бесплатные билеты.
* **Обновление программы** кнопкой «⬆ Обновить программу» (и само при
  запуске): берёт новую версию со страницы выпуска на GitHub, сверяет
  контрольную сумму и ставится только после вашего «Да».
* **Генерирует билеты** одним из способов: чаще выпадавшие, строго
  самые частые, реже выпадавшие, давно не выпадавшие, смесь, полностью
  случайно.
* Щелчок по шару **закрепляет** число (оно войдёт в каждый билет),
  второй щелчок **исключает** его, третий — возвращает как было.
* Для каждого билета пишет, сколько раз он совпал бы в прошлом на 3, 4, 5
  чисел.

## Как скачать и запустить

1. Откройте страницу выпуска:
   https://github.com/simafon1-cyber/lotto-generator/releases/tag/lottery-latest
2. Скачайте файл для своего Mac:
   * Apple M1/M2/M3/M4 → `LottoGenerator-mac-apple-silicon.zip`
   * Intel → `LottoGenerator-mac-intel.zip`

   Какой у вас: меню  → «Об этом Mac» → строка «Чип» (Apple M…) или
   «Процессор» (Intel).
3. Двойной щелчок по zip → появится «Lotto Generator». Перетащите его в
   папку «Программы».
4. Первый запуск: Mac скажет, что не может проверить разработчика
   (программа не куплена в App Store и не подписана платным сертификатом
   Apple). Нажмите «Готово», затем откройте «Системные настройки» →
   «Конфиденциальность и безопасность», прокрутите вниз и нажмите
   **«Всё равно открыть»**. Это нужно сделать один раз.

## Честно о шансах

Шары не помнят прошлых тиражей. Число, которое выпадало чаще, **не**
выпадет с большей вероятностью в следующий раз. Шанс главного приза:
Lotto 6/49 — 1 к 13 983 816; Lotto Max (7 из 52) — 1 к 133 784 560 на
линию, около 1 к 33 млн на игру из 4 линий, какие бы числа ни были выбраны. Вкладка «Честно о шансах» в программе показывает, что
разброс частот — обычный для случайной лотереи.
