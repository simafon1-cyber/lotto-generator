# Lotto Generator на iPhone — установка через Xcode

Нужно один раз, примерно 15 минут. Потом программа сама получает новые
тиражи и новые версии — переустанавливать не нужно. С платной учётной
записью разработчика Apple приложение работает **год**, затем — нажать
▶ в Xcode ещё раз.

Что внутри: оболочка открывает страницу
`https://simafon1-cyber.github.io/lotto-generator/` (всегда свежая версия и
тиражи). Без интернета открывается копия, вложенная в приложение.

---

## Шаг 0. Скачать файлы

1. Откройте https://github.com/simafon1-cyber/lotto-generator
2. Зелёная кнопка **Code** → **Download ZIP**. Двойной щелчок по zip —
   появится папка `lotto-generator-main`.

Понадобятся из неё: файл `ios/ContentView.swift`, картинка
`ios/AppIcon-1024.png` и папка `web`.

## Шаг 1. Новый проект

1. Откройте **Xcode** → **File → New → Project…**
2. Вверху выберите **iOS**, плитка **App** → **Next**.
3. Заполните:
   * **Product Name:** `LottoGenerator`
   * **Team:** ваша платная учётная запись (если пусто — **Add Account…**
     и войдите своим Apple ID).
   * **Organization Identifier:** например `com.ivanov` (любое, латиницей).
   * **Interface:** SwiftUI, **Language:** Swift. Галочки ниже — снять.
4. **Next** → выберите, куда сохранить (например, «Документы») → **Create**.

## Шаг 2. Вставить код

1. Слева в списке файлов щёлкните **ContentView.swift**.
2. Выделите весь текст справа (**⌘A**) и удалите.
3. Откройте скачанный `ios/ContentView.swift` в «Тексте» (TextEdit),
   скопируйте всё (**⌘A**, **⌘C**) и вставьте в Xcode (**⌘V**).
4. Файл **LottoGeneratorApp.swift** не трогайте.

## Шаг 3. Добавить папку web (работа без интернета)

1. Перетащите папку `web` из Finder в Xcode — в левый список, прямо на
   жёлтую папку `LottoGenerator`.
2. В появившемся окне:
   * **Copy items if needed** — галочка;
   * **Create folder references** — выбрать (папка станет **синей**);
   * **Add to targets: LottoGenerator** — галочка.
3. **Finish**.

## Шаг 4. Значок

1. Слева щёлкните **Assets** → **AppIcon**.
2. Перетащите `ios/AppIcon-1024.png` в пустой квадрат.

## Шаг 5. Поставить на iPhone

1. Подключите iPhone кабелем к Mac, разблокируйте, на вопрос «Доверять
   этому компьютеру?» — **Доверять**.
2. Режим разработчика у вас уже включён (Настройки → Конфиденциальность и
   безопасность → Режим разработчика).
3. В Xcode вверху посередине, где написано имя устройства, выберите
   **ваш iPhone**.
4. Нажмите **▶** (или **⌘R**). Первый раз сборка занимает минуту-две.
5. Если iPhone пишет «Ненадёжный разработчик»: Настройки → Основные →
   **VPN и управление устройством** → ваша учётная запись → **Доверять**.
   Затем снова ▶.

Готово: на экране iPhone значок **LottoGenerator**.

## Если что-то пошло не так

| Что видите | Что сделать |
|---|---|
| Красная ошибка «Signing requires a development team» | Шаг 1, пункт Team: выберите учётную запись. Или слева синий значок проекта → вкладка **Signing & Capabilities** → **Team**. |
| «No such module WebKit» или много красных ошибок | Проверьте, что вставили код целиком, начиная со строки `// Lotto Generator для iPhone`. |
| Приложение открылось, но пусто без интернета | Шаг 3: папка `web` должна быть **синей**. Удалите её из списка и добавьте заново с «Create folder references». |
| Пишет «Нет связи — показаны тиражи, загруженные раньше» | Нет интернета. С интернетом тиражи обновятся сами. |

Сфотографируйте экран с ошибкой и пришлите — разберём.

## Билеты на Mac и iPhone

Списки «Мои билеты» на Mac и на iPhone хранятся отдельно. Перенести:
вкладка «Мои» → **Сохранить файл** (на iPhone откроется меню
«Поделиться» — отправьте себе AirDrop'ом на Mac) → на другом устройстве
**Загрузить файл**. Формат один и тот же (`my_tickets.json`).
